# 代理工作记录

本目录用于保存历史验证和排查上下文，不作为产品能力、部署状态或用户操作的说明。记录可能描述过去的实现；当前行为以代码和测试为准。

用户文档在 README 和 docs，开发流程在 CONTRIBUTING.md。不要把临时实验、对话过程或未实现的设想复制进用户文档。

部署约定：每次更改后都要部署到本地开发测试环境。除非用户明确要求部署到远端服务器，否则不操作远端服务器。本地与远端保留各自的 Bot 配置。

后续方向：作者资料可扩展为独立的 X Profile metadata 追踪实体；本期继续保留随帖子采集的 x.profile 快照，不增加独立监控。用户发帖列表与登录账号书签属于后续可选列表能力；书签集合及成员关系必须按租户/Connection 私有隔离，即使其中的帖子本身是 public。
