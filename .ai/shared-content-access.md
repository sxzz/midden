# 单份内容与访问授权：决策记录（2026-10-02）

当前规则见 `docs/architecture.md` 的公私隔离一节。这里只记录规则背后由用户确认、代码里看不出来的取舍。

- 内容不属于任何租户，也不记录创建者；授权按租户记录，与用哪个账号证明无关。
- 新获得授权的租户可以读该对象的全部历史版本，包括授权前他人抓取的 private 版本。
- 撤销后保留此前已可读的版本，作为存档；只隐藏 `revoked_at` 之后他人抓到的版本。
- 授权不定期复核，接受“账号失去访问后，在下次自己抓取或检查前仍能看到他人新抓的版本”。
- 迁移合并已有重复数据后，部分租户的计量用量会上升；已接受，不做额度补偿。
- 迁移在生产备份上演练过：重复收藏合并，没有内容丢失。
